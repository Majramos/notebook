## Types of Correlation Coefficients

- [Pearson correlation](https://en.wikipedia.org/wiki/Pearson_correlation_coefficient) (r)
- [Spearman's rank correlation](https://en.wikipedia.org/wiki/Spearman%27s_rank_correlation_coefficient) (p)
- [Kendall rank correlation](https://en.wikipedia.org/wiki/Kendall_rank_correlation_coefficient) (t)
- [Multiscale Graph Correlation](https://amstat.tandfonline.com/doi/abs/10.1080/01621459.2018.1543125?journalCode=uasa20#.Xh9G41X7SUk) (mgc)
- [Goodman and Kruskal's correlation](https://en.wikipedia.org/wiki/Goodman_and_Kruskal%27s_gamma)
    - Good to use with gradient data -> classify as positive, 0, negative
    - https://www.youtube.com/watch?reload=9&v=df_ERKZ_vV4
    - https://www.statisticshowto.datasciencecentral.com/gamma-coefficient-goodman-kruskal/
- [Point-biserial correlation](https://en.wikipedia.org/wiki/Point-biserial_correlation_coefficient)
- [Theil–Sen estimator](https://en.wikipedia.org/wiki/Theil%E2%80%93Sen_estimator)
    - Does not return correlation only the line, need to find a way of obtaining a correlation
- [Siegel estimator / Repeated median regression](https://en.wikipedia.org/wiki/Repeated_median_regression)
    - Does not return correlation only the line, need to find a way of obtaining a correlation
- [Coefficient of determination](https://en.wikipedia.org/wiki/Coefficient_of_determination) (r2)
